# odin-sketch
Etch-a-Sketch project from The Odin Project Foundations Course

https://www.theodinproject.com/lessons/foundations-etch-a-sketch

Part of the JavaScript Basics lesson on The Odin Project. We are tasked to build a basic browser version
of a sort of sketchpad. They call it an Etch-A-Sketch, but there are no controls or "knobs" to the UI.
Using a CSS Flexbox grid generated in JavaScript, we are to have the squares change color when moused over as well as take user input for the size of the grid.
